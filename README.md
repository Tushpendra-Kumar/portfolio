Welcome to the official repository of **Tushpendra Kumar's** personal software engineering portfolio. 

Designed and engineered from scratch with inspiration from **macOS Sequoia, Apple VisionOS Liquid Glass, and Bento Grid Design Matrices**, this website represents high-standard frontend craftsmanship, pristine typography, fluid micro-interactions, and high-performance vanilla JavaScript architecture with zero framework bloat.

- 🌌 **Neural Particle Starfield:** Hardware-accelerated dynamic canvas rendering floating stars and ambient nebulas at a steady 60 FPS.
- 📱 **100% Adaptive Across Devices:** Engineered with a responsive multi-column layout on Desktop and collapsing into touch-friendly cards on Mobile.

## 🚀 Local Development Setup

To run this portfolio locally on your workstation:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tushpendra-Kumar/portfolio.git
   cd portfolio
   ```

2. **Run with any live static server:**
   ```bash
   # Using npx serve
   npx serve .

   # Or using Python 3
   python -m http.server 5500
   ```

3. **Open in browser:**
   ```
   http://127.0.0.1:5500
   ```

## ⚡ Deployment Instructions

### Deploy to Vercel (1-Click Automated CI/CD)
1. Navigate to [Vercel Dashboard](https://vercel.com/dashboard).
2. Click **"Add New..."** &rarr; **"Project"**.
3. Import your GitHub repository: **`Tushpendra-Kumar/portfolio`**.
4. Leave Framework preset as **Other** (Root directory: `./`).
5. Click **"Deploy"**. Any future `git push` to `main` will automatically trigger a zero-downtime production deployment!
