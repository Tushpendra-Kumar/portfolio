## ⚡ Deploy to Vercel (Choose either method)

### Option 1: Via GitHub (Recommended for automatic updates)
1. Initialize git and push the `portfolio` folder to a new GitHub repo:
   ```bash
   cd "d:\My Resume\portfolio"
   git init
   git add .
   git commit -m "Initial commit: Apple Glass Portfolio"
   # Create a repo on github.com/new named 'portfolio'
   git remote add origin https://github.com/Tushpendra-Kumar/portfolio.git
   git branch -M main
   git push -u origin main
   ```
2. Open **[vercel.com](https://vercel.com)** and log in with your GitHub account.
3. Click **"Add New..."** -> **"Project"**.
4. Select your **`portfolio`** repository.
5. Keep default settings (Framework: *Other*) and click **"Deploy"**.
6. Within 15 seconds, your site will be live with a free custom URL like `https://tushpendra-kumar.vercel.app`!

---

### Option 2: Deploy directly from PowerShell (No GitHub needed)
1. Open PowerShell and go to this directory:
   ```powershell
   cd "d:\My Resume\portfolio"
   ```
2. Run Vercel CLI via npx:
   ```powershell
   npx vercel
   ```
3. Follow the on-screen prompt to log in and confirm default settings.
4. For production live domain, run:
   ```powershell
   npx vercel --prod
   ```
